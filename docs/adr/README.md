# Architecture Decision Records

Cada ADR registra **uma** decisão relevante: o contexto, o que foi decidido, as alternativas descartadas e as consequências. ADRs não são reescritos quando a decisão evolui; recebem um adendo (como o 0007) ou são substituídos por um novo ADR.
